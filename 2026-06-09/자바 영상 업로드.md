# 자바 영상 업로드

## 예제

```java
import com.google.api.client.googleapis.auth.oauth2.GoogleCredential;
import com.google.api.client.googleapis.javanet.GoogleNetHttpTransport;
import com.google.api.client.http.FileContent;
import com.google.api.client.json.gson.GsonFactory;
import com.google.api.services.youtube.YouTube;
import com.google.api.services.youtube.model.Video;
import com.google.api.services.youtube.model.VideoSnippet;
import com.google.api.services.youtube.model.VideoStatus;

import java.io.File;
import java.io.FileInputStream;
import java.util.Arrays;

/**
 * YouTube에 영상을 업로드하는 예제 코드
 */
public class YouTubeVideoUploader {

    // YouTube Data API v3 서비스 생성
    private static YouTube createYouTubeService() throws Exception {
        // Google Credential 생성 (client_secret.json 파일 필요)
        // https://console.cloud.google.com/ 에서 OAuth 클라이언트 ID 생성
        GoogleCredential credential = GoogleCredential.fromStream(
                new FileInputStream("client_secret.json"))
                .createScoped(Arrays.asList("https://www.googleapis.com/auth/youtube.upload"));

        // HTTP_TRANSPORT와 JSON_FACTORY 생성
        return new YouTube.Builder(
                GoogleNetHttpTransport.newTrustedTransport(),
                GsonFactory.getDefaultInstance(),
                credential)
                .setApplicationName("YouTubeVideoUploader")
                .build();
    }

    /**
     * 영상 업로드 메서드
     */
    public static void uploadVideo(String videoFilePath, String title, String description) throws Exception {
        // YouTube 서비스 생성
        YouTube youtubeService = createYouTubeService();

        // 영상 파일 로드
        File videoFile = new File(videoFilePath);
        FileContent mediaContent = new FileContent("video/mp4", videoFile);

        // Video 객체 생성
        Video video = new Video();

        // VideoSnippet 설정 (제목, 설명, 태그 등)
        VideoSnippet snippet = new VideoSnippet();
        snippet.setTitle(title);
        snippet.setDescription(description);
        snippet.setTags(Arrays.asList("java", "youtube", "video"));
        snippet.setPosition(new GeoPoint(37.5665, 126.9780)); // 위치 정보 (선택사항)
        video.setSnippet(snippet);

        // VideoStatus 설정 (공개 설정)
        VideoStatus status = new VideoStatus();
        status.setPrivacyStatus("public"); // public, private, unlisted
        video.setStatus(status);

        // 업로드 요청 실행
        YouTube.Videos.Insert insertRequest = youtubeService.videos()
                .insert("snippet,status", video, mediaContent);

        Video response = insertRequest.execute();

        System.out.println("Upload successful!");
        System.out.println("Video ID: " + response.getId());
        System.out.println("Title: " + response.getSnippet().getTitle());
    }

    public static void main(String[] args) throws Exception {
        // 영상 업로드 실행
        uploadVideo(
                "/path/to/video.mp4",
                "내 영상 제목",
                "이 영상은 Java로 업로드했습니다."
        );
    }
}
```

## 설명

### 왜 이렇게 쓰는지

1. **GoogleCredential.fromStream()** - OAuth2 인증을 위해 Google Cloud Console에서 다운로드한 `client_secret.json` 파일을 읽어옴
2. **createScoped()** - YouTube 업로드 권한(`youtube.upload`)을 포함한 범위 지정
3. **YouTube.Builder()** - YouTube API 서비스 인스턴스 생성
4. **FileContent** - 업로드할 영상 파일을 `FileContent`로 감쌈
5. **VideoSnippet** - 영상의 메타데이터 (제목, 설명, 태그, 위치 등)
6. **VideoStatus** - 영상의 공개 상태 (public, private, unlisted)

### 주의할 점

- **client_secret.json** - Google Cloud Console에서 OAuth 클라이언트 ID를 생성하고 JSON 파일을 프로젝트에 포함해야 함
- **API 사용 요금** - YouTube Data API는 일일 할당량이 있으며, 업로드 작업은 고 비용 연산
- **파일 크기 제한** - YouTube API는 일반 영상 업로드 시 파일 크기 제한이 있음 (일반 계정은 128GB 또는 12시간)
- **승인 절차** - 첫 실행 시 사용자 인증 (OAuth consent screen) 필요

### 자주 하는 실수

1. **client_secret.json 경로 오류** - 경로를 확인하고,(relative path vs absolute path)
2. **API 활성화 누락** - Google Cloud Console에서 YouTube Data API v3를 활성화해야 함
3. **권한 범위 잘못 지정** - 업로드에는 `youtube.upload` 스코프 필요
4. **HTTPS 프록시 문제** - corporate network에서 HTTPS 프록시 설정 필요

## 함께 학습하면 좋은 것

- **Google Cloud Console 설정** - OAuth 클라이언트 ID 생성 방법
- **YouTube Data API v3** - 전체 API 문서 및 다른 기능 (동영상 정보 조회, 재생목록 관리 등)
- **Resumable Upload** - 큰 파일을 업로드할 때 사용하는 확인 가능한 업로드 방식
- **미디어 업로드 전략** - 프로그레시브 업로드, 청크 업로드
- **YouTube Partner Program** - 광고 수익화를 위한 파트너 프로그램 가입
