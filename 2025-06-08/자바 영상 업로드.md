# 자바 영상 업로드

## 예제

```java
// 1. HttpClient 관련 import (Java 11+ 기본 포함)
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

// 2. 영상 파일 경로 설정
Path videoPath = Paths.get("path/to/your/video.mp4"); // 업로드할 영상 파일

// 3. 파일 바이너리 읽기
byte[] videoBytes = Files.readAllBytes(videoPath);

// 4. HttpClient 생성
HttpClient client = HttpClient.newHttpClient();

// 5. HTTP POST 요청 생성 (multipart/form-data)
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://your-upload-endpoint.com/upload")) // 업로드 API URL
    .header("Content-Type", "multipart/form-data; boundary=---CustomBoundary")
    .POST(HttpRequest.BodyPublishers.ofByteArrays(videoBytes)) // 바이트 데이터로 전송
    .build();

// 6. 응답 처리
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println("상태 코드: " + response.statusCode());
System.out.println("응답 본문: " + response.body());
```

### 대안: 자바 8 호환 HttpClient (Apache HttpClient 사용)

```java
// Maven 의존성
// <dependency>
//     <groupId>org.apache.httpcomponents</groupId>
//     <artifactId>httpclient</artifactId>
//     <version>4.5.14</version>
// </dependency>

import org.apache.http.HttpEntity;
import org.apache.http.HttpResponse;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.entity.mime.MultipartEntityBuilder;
import org.apache.http.entity.mime.content.FileBody;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.util.EntityUtils;

// 파일 업로드
File videoFile = new File("path/to/your/video.mp4");
CloseableHttpClient httpClient = HttpClients.createDefault();
HttpPost postRequest = new HttpPost("https://your-upload-endpoint.com/upload");

FileBody fileBody = new FileBody(videoFile, org.apache.http.entity.ContentType.DEFAULT_BINARY);
HttpEntity entity = MultipartEntityBuilder.create()
    .addPart("file", fileBody) // 'file'은 서버에서 기대하는 파라미터명
    .build();

postRequest.setEntity(entity);

HttpResponse response = httpClient.execute(postRequest);
String responseBody = EntityUtils.toString(response.getEntity());
System.out.println("응답: " + responseBody);
httpClient.close();
```

## 설명

- **Java 11+ HttpClient**: 표준 라이브러리로 HTTPS 전송 가능 → 가볍고 간단
  - `Files.readAllBytes()`로 파일 전체를 메모리에 읽어옴 → 대용량 파일은 주의
  - 바이트 배열 직접 전송 또는 `FileBody` 사용 가능

- **Apache HttpClient (Java 8 호환)**: 외부 라이브러리지만 널리 사용
  - `MultipartEntityBuilder`로 `multipart/form-data` 구성
  - `FileBody`로 파일 전용 전송 → 메타데이터(제목, 설명 등)도 추가 가능

- **업로드 API 주의사항**:
  - 서버가 `multipart/form-data`를 기대하는지 확인
  - Content-Type 헤더에 `boundary` 파라미터 추가 필수 (자동으로 설정됨)
  - 대용량 파일은 청크 업로드 또는 서버의 presigned URL 사용 권장
